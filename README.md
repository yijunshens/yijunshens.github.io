# Yijun Shen's Homepage

Personal academic website of Yijun Shen (沈逸骏), built with Jekyll and hosted on GitHub Pages.

**Website:** [yijunshens.github.io](https://yijunshens.github.io/)

## Editing

- `_pages/about.md`: biography, research interests, experience, and publications.
- `_config.yml`: site settings and profile links.
- `images/`: photos and publication figures.
- `assets/css/homepage.css`: custom homepage styles.

Based on [AcadHomepage](https://github.com/RayeRen/acad-homepage.github.io). See [LICENSE](LICENSE) for the MIT license.
